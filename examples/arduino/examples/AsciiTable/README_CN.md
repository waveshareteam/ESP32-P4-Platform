# AsciiTable

[English](README.md)

Arduino 显示文本渲染示例。它会在受支持的 DSI 显示屏上绘制 ASCII 表格。

## 难度

初级。

## 所需硬件

- ESP32-P4 开发板。
- 受支持的 DSI 显示屏。
- 在 Arduino 开发板设置中启用 PSRAM。

## 运行方法

1. 阅读 [../../README_CN.md](../../README_CN.md)。
2. 打开 `AsciiTable.ino`。
3. 选择正确的开发板、端口和 PSRAM 设置。
4. 如有需要，设置 `CURRENT_SCREEN`。
5. 上传 sketch。

## 预期行为

显示屏显示由 ASCII 字符构成的行和列。
