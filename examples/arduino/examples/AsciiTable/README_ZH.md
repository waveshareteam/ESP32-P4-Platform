# ASCII 字符表

[English](README.md) | [简体中文](README_ZH.md)

## 功能

使用 Arduino_GFX 绘制 ASCII 字符表。

## 硬件需求

带 PSRAM 的 ESP32-P4 开发板、USB 数据线，以及兼容的 DSI 显示屏。

## 怎么运行

按 [Arduino 环境说明](../../README_ZH.md)完成配置，打开 `AsciiTable.ino` 并使用其中的开发板选项上传。上传前通过 `CURRENT_SCREEN` 选择连接的屏幕。

## 预期现象

显示屏按行列排列 ASCII 字符。
